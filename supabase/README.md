# Future backend placeholder

The current `/caautobodyadmin` experience is a frontend mockup. Its OTP screens do not send email, verify a code, create a session, or grant real access. Team profiles and audit events are stored only in the current browser for preview purposes.

When the project is ready for a backend phase, this folder can hold Supabase migrations for administrator accounts, email OTP, Row Level Security, audit records, content data, and media storage.

Do not place service-role keys in browser-exposed environment variables.
